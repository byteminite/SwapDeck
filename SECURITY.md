# Security

SwapDeck switches Steam accounts and, if you connect an account for stats, keeps Steam's sign-in token on your PC
(encrypted by Windows). So security problems matter, and reports are very welcome.

## Reporting a problem

Please report it **privately**, not as a public issue:
[Report a vulnerability](https://github.com/byteminite/SwapDeck/security/advisories/new) (GitHub's private reporting).

Helpful to include:

- What the problem is and what someone could do with it
- How to repeat it, and the SwapDeck version (Settings → About)
- Never include your own passwords, Steam Guard codes or tokens

You'll get an answer as soon as possible. Fixes ship as a normal update, which installed copies pick up within minutes.

## Supported versions

Only the latest release gets fixes. The installer updates itself, so most people are on it already.

## What SwapDeck keeps

Everything stays on your PC, in `%APPDATA%\SwapDeck`. See [Privacy in the README](README.md#privacy) for exactly what is
read, stored and sent.
